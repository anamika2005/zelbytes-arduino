# Sensor Placement Notes

## Overview

This document records the physical placement and mounting conditions of all sensors used in the Analog Sensor Calibration Suite.

---

## LDR Placement

| Parameter | Description |
|-----------|-------------|
| Location | Breadboard-mounted near Arduino Uno |
| Exposure | Ambient room lighting |
| Height | Desk-level placement |
| Notes | Sensor kept unobstructed to receive surrounding light |

### Observation

LDR readings changed significantly when covered by hand and when exposed to room light, confirming proper operation.

---

## DHT22 Placement

| Parameter | Description |
|-----------|-------------|
| Location | Mounted on breadboard |
| Airflow | Open room environment |
| Heat Sources | Kept away from direct heat sources |
| Mounting | Upright position |

### Observation

Stable temperature and humidity values were obtained using a 2-second sampling interval.

---

## HC-SR04 Ultrasonic Sensor Placement

| Parameter | Description |
|-----------|-------------|
| Orientation | Facing a flat target surface |
| Mounting | Fixed position during testing |
| Test Distances | Approximately 10 cm and 30 cm |
| Measurement Direction | Perpendicular to target surface |

### Observation

Accurate readings were obtained when the target surface was flat and directly in front of the sensor.
